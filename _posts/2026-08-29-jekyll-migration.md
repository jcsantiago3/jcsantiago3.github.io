# Hello, Jekyll

I'm currently migrating my portfolio website from a plain HTML, CSS, and JavaScript site to Jekyll.

The goal is to keep the existing design while making it easier to maintain and eventually add a blog.

## Why Jekyll?

I wanted a way to write posts without manually creating an HTML page for every article.

With Jekyll, I can write my posts in Markdown and let the site generator handle the HTML.

## What I'm Working On

The current site is still being developed, but this is the beginning of the transition.
